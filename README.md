# Рилсы про ИИ-агентов: от чужого залетевшего ролика до своего

Пайплайн, который находит популярные англоязычные рилсы про ИИ-агентов и автоматизацию,
пересказывает их для русскоязычной аудитории и собирает свой ролик в стиле pronin.media:
рисованный аватар в начале, дальше динамичная минималистичная «презентация», субтитры, живое демо.

Первый готовый ролик: [`reels/agent-team/agent-team.mp4`](reels/agent-team/agent-team.mp4)
(«Отдел из ботов, где работает один человек», 59 с, донор — @sebastianhardy_, 460 тыс. просмотров).

## Шаги

| Шаг | Команда | Что делает |
|---|---|---|
| 1. Поиск | `python -m pipeline.scout` | Apify: рилсы по хештегам (`#aiagents`, `#aiautomation`, `#n8n`…) и каналам-донорам, фильтр «англоязычное + по теме», ранжирование по просмотрам и вовлечённости с поправкой на свежесть |
| 2. Донор | `python -m pipeline.fetch <ссылка> --slug <имя>` | Apify `instagram-reel-scraper` (`includeDownloadedVideo`, `includeTranscript`): видео, расшифровка, кадры 1/сек и контактные листы для просмотра |
| 3. Сценарий | `python -m pipeline.script <имя>` | Черновик на русском через LLM (fal): 5 частей — хук, завязка, кульминация, развязка, заключение; простые слова, валюта в рублях. **Вычитать руками** |
| Демо | `python -m pipeline.demos.agent_team` | Реально запускает то, о чём ролик (здесь — команду из 4 агентов + главного), ответы попадают в видео |
| 4. Голос | `python -m pipeline.voice <имя>` | ElevenLabs v3 (голос Lily) двумя цельными дублями, ускорение ×1.5 без изменения тембра, тайминг каждого слова через распознавание речи |
| 5. Аватар | (автоматически при рендере) | Рисованный аватар + свой рот по громкости голоса, моргание, «дыхание». Опционально `python -m pipeline.avatar talk <имя>` — анимация моделью `veed/fabric-1.0` |
| 6. Сборка | `python -m pipeline.render <имя>` | Remotion: сцены, субтитры, звук → `reels/<имя>/<имя>.mp4`. `--stills` — по кадру на реплику для быстрой проверки |
| 7. Публикация | `python -m pipeline.publish <имя> --yes` | Instagram Graph API, загрузка файла напрямую. Без `--yes` только показывает, что уйдёт |

## Формат ролика

Дизайн по шаблону-коллажу: синий фон, крафтовый лист в руках, жёлтые звёзды, мегафон (`assets/template/board.png`
вырезан из шаблона).

- **Вступление (хук)** — на листе собирается заголовок из букв «как из газеты»: каждая буква на своём клочке
  цветной бумаги и своим шрифтом, влетает крупно и садится на место (`video/src/Ransom.tsx`, визуал `ransom`).
- **Дальше** — на том же листе анимированная презентация: каждая реплика — своя сцена, синхронизированная со словами
  (`video/src/scenes.tsx`). Карточки — бумажки коллажа: кремовые, выделенные — жёлтые, плашки — красные.
- **Под листом** — белые субтитры (всегда одинаковые, по центру), ниже у самого нижнего края — рисованный аватар.
  Аватар весь ролик говорит: рот двигается по громкости голоса, моргает, чуть покачивается.
  Новый аватар: `python -m pipeline.avatar stylize <ссылка на фото анфас>`, затем поправить координаты рта и глаз
  в `assets/avatar/face.json`.
- **Демо** — показываем, как это работает на деле: скрипт в `pipeline/demos/` по-настоящему запускает пример,
  а сцены `demo_run` и `phone` показывают настоящие ответы.
- **Сценарий** — `reels/<имя>/script.json`: реплики с актом (`hook/setup/climax/resolution/conclusion`) и типом визуала.

## Инструменты из подборки awesome-claude-video-skills

Из 373 репозиториев под этот формат (аватар + объясняющая презентация + субтитры, русский язык, Reels) подходят:

- **Remotion** ([remotion-dev/skills](https://github.com/remotion-dev/skills)) — основа сборки. Тот же стек у pronin.media; в тесте подборки — самый надёжный рендер. Свой дизайн задаём сами, поэтому ролики не выглядят «по умолчанию».
- **Принцип word-exact timing** из [claude-faceless-shorts-creator](https://github.com/hassancs91/claude-faceless-shorts-creator): сцены и субтитры привязаны к таймингу слов озвучки.
- **Instagram Reels на Remotion** ([remotion-ads](https://github.com/Maartenlouis/remotion-ads)): безопасные зоны 9:16, контент выше интерфейса Instagram.
- **Разбор донора по кадрам** ([viral-video-decomposer](https://github.com/sharon-laicc/viral-video-decomposer), [qisi-video-remix](https://github.com/wyuzhi/qisi-video-remix)): референс → сценарий → раскадровка.
- **Хуки и удержание** ([tiktok-video-skills](https://github.com/iart-ai/tiktok-video-skills)) — для правил сценария.
- На потом: [AutoMontage-Agent](https://github.com/mcdenil-skills/AutoMontage-Agent) (русскоязычный автомонтаж), [avatar-mix](https://github.com/Upload-Post/avatar-mix) (публикация сразу во все соцсети).

Не взяли: HyperFrames (в тесте подборки 23 минуты на 15-секундный ролик), HeyGen-скиллы (платный реалистичный аватар — противоположность рисованному).

## Установка

```bash
pip install numpy pillow pillow-heif
cd video && npm install
cp .env.example .env   # и вписать ключи
```

Нужны `ffmpeg` и Node 18+. Ключи хранятся только в `.env` (он в `.gitignore`).
